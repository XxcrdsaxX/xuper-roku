# 📺 XUPER(JGLCUSTOMS IPTV) para Roku

Repositorio dedicado a recopilar, organizar y documentar los archivos relacionados con **JGLCUSTOMS IPTV para Roku**.

Aquí encontrarás manuales, documentación y recursos necesarios para consultar el proceso de instalación y tener todos los archivos del proyecto en un solo lugar.

## 📂 Contenido del repositorio

| Archivo o carpeta               | Descripción                                                           |
| ------------------------------- | --------------------------------------------------------------------- |
| `manual_jglcustoms_rokutv.html` | Manual en formato HTML, con diseño visual y navegación por secciones. |
| `leer instalacion.txt`          | Documento de texto original con las instrucciones de instalación.     |
| `instalador/`                   | Archivos relacionados con el instalador, si se incluyen.              |
| `recursos/`                     | Imágenes y otros recursos complementarios.                            |

*La estructura puede cambiar a medida que se agreguen nuevos archivos.*

## 📖 Documentación

Puedes consultar las instrucciones de instalación desde el manual HTML o revisar el documento TXT original.

Se recomienda leer el manual completo y seguir las indicaciones en el orden establecido.

## 🎯 Objetivo

Mantener todos los archivos relacionados con JGLCUSTOMS IPTV para Roku organizados y disponibles desde un único repositorio, facilitando su consulta y conservación.

## ⚠️ Aviso

Este repositorio tiene fines informativos y de organización de archivos. Antes de utilizar cualquier archivo, revisa su contenido y asegúrate de conocer su procedencia.
